# Yuxuan Tang

Personal academic website for Yuxuan Tang.

## Pages

- `index.html`: About
- `research.html`: Research
- `presentation.html`: Presentations
- `teaching.html`: Teaching
- `css/yuxuan.css`: Small site-specific style adjustments
- `img/Yuxuan_Tang.jpg`: Profile photo

## Preview locally

```bash
cd /Users/tangyuxuan/Desktop/webpage/yxtang2020.github.io
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Publish

Copy the website files to the root of your `yxtang2020.github.io` repository,
then push them to the branch configured in GitHub Pages.
